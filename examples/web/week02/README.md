# Not kararı: JavaScript karşılığı

Programlamaya Giriş, ÇOMÜ Bilgi Güvenliği Teknolojisi.

## Çalıştırma

Bu klasördeki index.html dosyasını tarayıcıda aç. Ek paket veya sunucu gerekmez.

- index.html: sayfa yapısı ve erişilebilir etiketler.
- style.css: sayfanın görünümü.
- script.js: kullanıcı etkileşimi ve kararlar.

## Uygulama

49 → Kaldı, 50 → Geçti, 51 → Geçti testlerini dene. Boş, -1 ve 101 değerlerinde açıklayıcı hata mesajını kontrol et. 50 eşiği eğitim örneğidir; üniversitenin not yönetmeliği değildir. Tarayıcıdaki doğrulama gerçek sunucu güvenliğinin yerini tutmaz.
