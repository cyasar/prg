# İlk etkileşimli sayfam

Programlamaya Giriş, ÇOMÜ Bilgi Güvenliği Teknolojisi.

## Çalıştırma

Bu klasördeki index.html dosyasını tarayıcıda aç. Ek paket veya sunucu gerekmez.

- index.html: sayfa yapısı ve erişilebilir etiketler.
- style.css: sayfanın görünümü.
- script.js: kullanıcı etkileşimi ve kararlar.

## Uygulama

Düğmeye tıkla ve mesajın değiştiğini doğrula. HTML başlığını, CSS rengini ve JavaScript mesajını ayrı ayrı değiştir. Her değişiklikten önce sonucu tahmin et.

## YZ ile çalışma

Önce kendi değişikliğini planla. YZ’den kodu yazmasını istemek yerine bir ipucu iste. Sonucu test edip hangi satırın davranışı değiştirdiğini açıkla.
