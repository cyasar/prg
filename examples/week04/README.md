# Hafta 4: Döngüler ve tekrarlayan problemler

Python 3 dışında paket gerekmez. Önce kodu oku ve çıktıyı tahmin et.

Depo kökünde Windows için:

```sh
py examples/week04/countdown.py
```

macOS/Linux için py yerine python3 kullan. Her input sorusunu terminalde sırayla yanıtla.

- [countdown.py](countdown.py): while döngüsü koşul True olduğu sürece bloğu tekrarlar.
- [pin_bruteforce.py](pin_bruteforce.py): break anahtar sözcüğü döngüyü erken sonlandırır.
- [port_scanner_mock.py](port_scanner_mock.py): range(baslangic, bitis + 1) belirlenen port aralığında ardışık sayılar üretir.
- [traffic_accumulator.py](traffic_accumulator.py): toplam_bayt toplayıcı (accumulator) olarak kümülatif toplamı biriktirir.
- [port_filter_continue.py](port_filter_continue.py): continue ifadesi döngünün mevcut adımını hemen sonlandırıp bir sonraki adıma geçer.

Örneklerde belirtilen normal girdi biçimini kullan. abc gibi girdiler bazı örneklerde bilerek yönetilmez; hata türünü gözlemlemek dersin parçasıdır. Sayısal biçim ile geçerli değer aralığı farklıdır. Not eşiği ve yaş kategorileri yalnızca eğitim örneğidir. Gerçek parola veya kişisel veri kullanma.
